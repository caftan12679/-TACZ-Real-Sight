# TaCZ Real Ads

> 由 **DeepSeek Harness** 制作 · 原作者：https://b23.tv/u6Wgfrn

让 TaCZ 的瞄准手感更接近真实射击 —— 视野、抬枪节奏、枪械惯性、持枪姿态都做了调整。

---

## 它解决了什么问题

原版 TaCZ 只要开镜就缩小世界视野（FOV），不管装的是 4 倍镜、红点还是机瞄。

对真正的光学瞄准镜来说这没问题，但红点、全息、机械瞄具本身不带放大能力，现实里用它们瞄准视野和裸眼一样。游戏却把画面拉窄，视野变闷，还干扰目标搜索。

此外原版抬枪偏快、枪械跟手太死，缺少手持重物的迟滞感。

这个模组就是往「更真实」的方向掰。

---

## TaCZ 的两层 FOV

要理解这个模组，得先分清 TaCZ 内部两个独立参数：

| 参数 | 作用 |
|---|---|
| `WORLD_FOV_DYNAMICS` | **世界视野** —— 画面能看多宽，整个场景的透视 |
| `ITEM_MODEL_FOV_DYNAMICS` | **模型视野** —— 单独作用于第一人称枪模的投影 |

两者解耦：世界视野收窄会让整个场景放大，模型视野变化只让枪在屏幕上变大变小。

---

## 做了什么

### 1. 非光学瞄具不再缩小世界视野

模组读取瞄具的 `scope` 标志判断类型。红点、全息、机瞄开镜时倍率锁定为 **1.0**，画面保持裸眼宽度。

| 瞄具 | 原版 | 本模组 |
|---|---|---|
| 红点 / 全息 / 机瞄 | 视野缩窄 | **不变** |
| 光学放大镜（4x、6x 等） | 视野缩窄 | **保持原版** |

**可变倍率瞄具（LPVO、ELCAN、HAMR 等）按瞄具本身判定，不看当前档位** —— 这是关键。若按档位判断，拧回 1x 时会被误判成非光学镜，世界 FOV 和枪模位置都退回腰射状态，而实际成像仍是高倍视野，画面就会错乱。

### 2. 抬枪与持枪姿态

- 腰射时枪模下压，开镜时向玩家拉近，贴合贴腮瞄准的动作
- 部分手枪（taurus943 / rhino357 / taurus500）有单独的位置补偿
- 开镜速度放慢到原来的 **1 / 2.5**，并重映射进度曲线：前段快、后段缓，接近真实抬枪的重心转移

### 3. 枪械惯性

转动视角时枪模不跟手，而是滞后跟上来：

- 转动越猛滞后越小，最高偏航滞后 **18°**
- 抬头滞后 3°、低头滞后 4°
- 开镜时惯性减弱到 **75%**

纯视觉效果，不影响弹道。

### 4. 呼吸与随机抖动

手持武器会有细微晃动：

| 状态 | 偏航 | 俯仰 | 侧倾 |
|---|---|---|---|
| 待机 | 0.18° | 0.12° | 0.08° |
| 开火后 | 0.35° | 0.22° | 0.12° |

开火时频率更高，待机时隔 3~6 秒来一次。全部是视觉。

### 5. 开镜阻尼

改写 TaCZ 的二阶动力学参数（频率 0.7、阻尼 1.5、响应 0.25），让开镜过渡更有重量感，不会一碰就到。

---

## 关于放大镜仍然改变 FOV

这是**刻意保留**的，因为它是真实的光学现象。

现实里用倍率镜时，眼睛必须位于镜片的出瞳距离（eye relief）焦点上才能正常成像，这个过程本身就伴随视野收窄 —— 不是游戏做错了，而是光学器材的固有特性。

所以分工是：

- **1 倍瞄具** → 去掉游戏错误施加的视野变化
- **倍率瞄具** → 完整保留原版行为

## 安装

1. 安装 Forge 1.20.1
2. 把 TaCZ 1.2.0 和本模组一起放进 `mods/`
3. 启动游戏

不添加任何物品、方块或配置项，装上即生效。

---

## 构建

```bash
# TaCZ 的 jar 体积较大，不纳入版本库，需自行放入 libs/
cp tacz-forge-1.20.1-1.2.0.jar libs/

./gradlew build
```

产物在 `build/libs/`。

## 技术说明

基于 Mixin，注入点：

| Mixin | 目标 | 作用 |
|---|---|---|
| `CameraSetupEventMixin` | `CameraSetupEvent#applyScopeMagnification` | 重定向 `getAimingZoom()`，非光学瞄具返回 1.0 |
| `FirstPersonRenderGunEventMixin` | `FirstPersonRenderGunEvent#applyFirstPersonPositioningTransform` | 枪模轴向位置调整 |
| `FirstPersonGunLagMixin` | 同上 | 惯性、抖动、呼吸 |
| `AimDynamicsMixin` | `FirstPersonRenderGunEvent#<clinit>` | 改写阻尼参数 |
| `LocalPlayerAimMixin` | `LocalPlayerAim#aimProgressCalculate` / `getClientAimingProgress` | 开镜速度与曲线 |

`GunPose` 负责在模型里定位枪托支点（`findStockPivot`）和最靠后顶点（`rearCameraZ`）。

所有注入均为 `remap = false`（目标是第三方模组类，不涉及 Minecraft 成员映射）。
